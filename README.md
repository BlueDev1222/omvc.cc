# Ottawa Metropolitan Roleplay

Static community website for https://omvc.cc, hosted by GitHub Pages from main / root. Real HTML pages, shared CSS and a small script for mobile navigation and copying the CAD join code. No backend, email system, accounts, tracking or build dependencies.

## Pages
- index.html — dashboard and community resources
- departments.html — five departments and supplied Discord invites
- marketplace.html — supplied Roblox product links and VIP+ benefits
- cad.html — Melonly community link and join code

## Editing
Edit HTML directly; styles.css controls appearance and app.js handles interactions. Supplied brand artwork is in assets/. Keep CNAME set to omvc.cc. Run a static server from this directory to preview.

Content was taken from the owner's four supplied Markdown documents. The owner supplied the correct Roblox community link and confirmed Marketplace Terms means Roblox Terms of Use. RCMP had no Discord invite and is marked unavailable. Product prices are intentionally obtained from the linked Roblox listings.
